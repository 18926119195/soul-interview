## 用语小注（专利词 → 能拿来做什么）

### 来自 viz（连接可视化）

| 用语 | 能拿来做什么 |
| :--- | :--- |
| **Data page（数据页）** | 一块可摆进空间里看的记忆内容（对应你现在的一则印记/一段回答）。 |
| **Current page（当前页）** | 你正在盯着读的那一页；画面以此为锚。 |
| **Companion page（同伴页）** | 当前这条关系连到的对面那一页；用来并排对照。 |
| **Background / context pages（背景页）** | 其它页退到后面；不抢阅读，但关系还在。 |
| **Current connection（当前连接）** | 此刻聚焦的那一条关系；高亮它，其它线弱化。 |
| **Departure / arrival location（出发段 / 到达段）** | 连线对准的具体文字范围（段落级），不是整块气泡中心。 |
| **Span（跨度）** | 一段连续文字；连线两端各抓一段 span。 |
| **Beam（光束区域）** | 把「这段↔那段」画成看得见的带子/光带，方便在 3D 里看见关系。 |
| **Swooping（摆扫）** | 沿关系换页/换视角：从这条关系「甩」到对面页。 |
| **Sworfing（摆扫+缩放变形）** | 一边换关系/页，一边拉近拉远，过渡更顺。 |
| **Step（步进）** | 在当前页里上一条/下一条关系切换聚焦。 |
| **Viewing angle（视角）** | 拖动改变观察角，把缠在一起的页和线拨开看清。 |

### 来自 data（数据底层）

| 用语 | 能拿来做什么 |
| :--- | :--- |
| **Cell（单元）** | 最小可连接的一格内容（一句话、一小段）。 |
| **Slice（切片）** | 一包自洽的数据（例如「某一主题会话里的记忆」）；可单独成立，也可与其它切片合用。 |
| **Dimension（维度）** | 一种排序/排队方向（如时间先后、主题邻接）；用来决定单元怎么排、怎么插。 |
| **Actual connection（实际连接）** | 已经兑现、两边都认的连接。 |
| **Latent connection（潜伏连接）** | 「想连但还没并到一起时」记下的偏好；合用切片时再兑现。（你暂不做自动挖，可先只当「待确认的边」存盘。） |
| **Intercalation（夹入/插入）** | 把一段内容插进另一串内容中间，而不是整份覆盖。（对应：新印记插进某条记忆链的位置。） |
| **Choosing / target cell（选择单元 / 目标单元）** | 谁发起连接、连向谁。 |
| **Preflet（偏好子）** | 记录「我想连到谁/哪一维」的专用小结构。（你暂不自动跑规则；可先当「边的类型/备注」字段预留。） |
| **Conglomerate（聚合结构）** | 多个切片合用后看到的那一张总图（接近你的全局灵魂地图）。 |
| **Priority（优先级）** | 多段记忆抢同一位置时，谁先展示。（可后做；用来处理矛盾记忆。） |

## 1. 两份文档各管什么

**viz（CVS）**：管「怎么摆、怎么看、怎么沿关系动」。  
**data（intercalation）**：管「内容怎么切块、怎么在链上插入、连接偏好怎么记」。

前端 3D 主要吃 viz；段落级连线要能存下来，才需要 data 里那套「单元/切片/连接」最小存法——**不必一次上齐 preflet 自动解析**。

## 2. 建议你做的前端 3D / 交互（主清单）

| # | 专利用语 | 能拿来做什么 | 落在你项目哪 |
| :--- | :--- | :--- | :--- |
| 1 | Current page + Companion page | 点一条关系后，左右（或前后）两页并排对照 | 灵魂地图深化区，替代「只点开一个气泡」 |
| 2 | Current connection 高亮 + Step | 聚焦一条关系；上下切换下一条 | 灵魂地图主交互（「聚焦关系项」） |
| 3 | Departure / arrival + Span | 高亮两端具体段落，不是气泡中心点 | 印记正文内选段 → 存边 |
| 4 | Beam | 3D/空间里用光带连两段文字 | 替换现在模块中心到中心的细线 |
| 5 | Viewing angle | 拖视角，拨开重叠的页和线 | 灵魂地图：从 2D 平移升级为可转视角 |
| 6 | Zoom + Sworfing（可简化） | 拉远看全局，拉近看文字；切换关系时带一点过渡 | 灵魂地图相机 |
| 7 | Swooping | 确认一条关系后，镜头跟到同伴页 | 「沿关系走」，不是弹窗跳转 |
| 8 | Background pages | 未聚焦的页退到后方变淡 | 多印记时保持可读 |

**暂不做（你已说不要自动挖）：** 按 preflet 自动找相似段、自动画边。边仍可手选两段 span 创建。

## 3. 除了 3D，我建议先做的配套（否则 3D 是空壳）

| # | 配套 | 为什么 |
| :--- | :--- | :--- |
| A | **边要能存 span**（出发段/到达段的起止位置） | 没有它，Beam 只能连气泡中心，做不成「聚焦关系项」。 |
| B | **印记仍可整段展示，但允许内部选段** | 对接现有 MemoryModule，不先拆爆数据结构。 |
| C | **连接说明用自定义文案**（用户或 AI 写一句「这两段是什么关系」；不先做死枚举） | 时代意义在于关系是开放语义，模型能读懂自然语言；光束颜色/筛选可后置：对文案做轻量归类或由用户自选色，而不是先规定「相似/矛盾」名单。专利里的 flink type / preflet 在此只作「可附着的备注槽」，内容自由填写。 |
| D | **远处简化、近处出字（LOD）** | 印记一多，全量 3D 贴字会卡。 |
| E | **同行者星座先保持 SVG** | 那是人物共鸣层；别和「页↔页 Beam」混成一套，避免一次改爆。 |

**data 专利里建议「先借结构、后借自动化」：**  
用 Cell/Slice 的思路理解「一则印记 = 一页；一次会话主题 ≈ 一个 slice」；`latent connection` 可当作「用户画了但未确认」的边。Intercalation / priority 可放到更后面。

## 4. 改前 vs 改后（功能差异）

| 功能点 | 改前（现在） | 改后（结合两专利，按上表收敛） |
| :--- | :--- | :--- |
| 灵魂地图空间 | Canvas 2D 力导向；右键平移 | ✅ **透视页空间**（XYZ + stand-off）；可转 viewing angle；无隧道「柱子」 |
| 地图上的节点 | 整段印记气泡 + 隧道锚点卡 | 仍是印记，但当作 **data page**；聚焦时升为 current / companion |
| 连线 | 模块中心 ↔ 中心；多靠手动画 | **Beam** 连 **span↔span**；当前连接高亮 |
| 点开关系后 | 多半停在同一张平面图上 | **Swooping**：镜头/布局跟到同伴页；背景页退后 |
| 切换多条关系 | 几乎没有「当前连接」概念 | **Step**：上下一条关系，视图跟着对准 |
| 对照阅读 | 无并排两页 | Current + Companion **并排/前后对照** |
| 数据里的边 | 只存模块 ID | 加 **departure/arrival**（字符起止）；另存一条自由文本 **关系说明**（非死枚举） |
| 主题隧道会话 | 四条主题 + 独立对话 | 可继续当 **slice** 容器；先不改聊天主流程 |
| 同行者星座 | SVG 人物星点 | **先不动**；与 Beam 关系图分层 |
| 自动发现连接 | 无 | **仍不做**；只预留类型字段 |

## 5. 建议实现顺序

1. **边的 span 存盘**（功能 A）——✅ 已落地：边上存 departure/arrival + 自定义关系说明。  
2. **灵魂地图对照模式**：✅ 点选连接后底部对照坞；两侧拖选写入 span；Beam 高亮。  
3. **Current connection + Step**：✅ E/C 或对照坞按钮步进。  
4. **Viewing angle + 背景页弱化**：✅ 远近 LOD（阅读面全文 / 中距略写 / 远处只留页形）；对照时阅读相机更正面。  
5. **Swooping 过渡**：✅ 选线/步进/「摆扫到对面」；真 stand-off 更近更正对。  
6. **Zoom + Sworfing / Slice 重排**：✅；视图控件收入右下「视图」小口。  
7. **Beam 按 span 锚点**：✅ 矩形光带 + 关系写在带上；无 span 时坞内引导。  
8. **并排 / 叠加**：✅ 对照坞可切 stand-off 与 overlay。  
9. **preflet / 自动夹入**：仍不做。

### 你怎么验证

1. 进入深化阶段灵魂地图。  
2. **Shift+拖** 在两则印记间连线 → 底部出现对照坞。  
3. 左右正文里**拖选文字** → 中间预览出现出发段/到达段；写一句关系说明；看 Beam 是否更贴段落。  
4. 点另一条线或按 **E/C** 步进；按 **F** 或「摆扫到对面」（应带一点拉近）。  
5. **滚轮** 或右下角「拉近/拉远」；**⌥Option+右键** 或视角按钮。  
6. 右下角切 **按隧道 / 按时间**，看印记重排动画；再切回 **自由**。

## 一句话

- **viz** 告诉你灵魂地图怎么「看、转、沿关系走」。  
- **data** 告诉你边和页怎么「切、插、记偏好」——你现阶段 mainly 用它的 **span/边存法**，不是它的自动 intercalation。  
- 对你项目：**主改灵魂地图 + 边模型；聊天与同行者星座先稳住。**
