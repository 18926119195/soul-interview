# 设计伙伴 10 人 · 招募与 4 周验证

> **目标**：用最低成本验证「有人愿意再来」，而不是一上来 50 人公测。  
> **楔子**：帮用户把模糊回忆/情绪，变成愿意继续写下去的结构化记忆。  
> **成功标准**：10 人里 **≥3 人** 愿意第二次使用，并愿意 **10 分钟口述反馈**。

---

## 一、为什么先 10 人，不是 50 人

| 50 人公测 | 10 人设计伙伴 |
|-----------|----------------|
| 你要同时救火稳定性 + 反馈 | 先验证价值，再扩量 |
| API / VPS 压力大 | BYOK + 小 VPS 够用 |
| 反馈噪音大 | 每人可以深聊 |
| 卖设备后容易崩盘 | 可约时间、可暂停 |

**扩到 30–50 人的条件（4 周后看）：**

- ≥3/10 愿意第二次来  
- ≥2/10 说出「我愿意为 XX 付钱」或等价承诺（早鸟订阅 / 推荐朋友）  
- 你每周只改 1 个点，仍然跟得上  

---

## 二、招什么人（画像）

优先 **3 类**，每类 3–4 人即可：

| 类型 | 为什么有价值 |
|------|----------------|
| **爱写日记 / 回忆录的人** | 天然需要「深化回忆」 |
| **正在经历转折的人**（换工作、失恋、毕业） | 情绪 → 叙述需求强 |
| **投资人 / 产品朋友（会直言）** | 帮你看体验和商业表述 |

**不要招：**

- 只愿意点两下就走的人  
- 期望「心理治疗」的专业求助者（产品边界不同，风险高）  
- 同一时间超过 15 人（你会过载）

## 五、访谈脚本

### 5.1 试用前（2 分钟，口头或文字）

1. 你最近有没有「想写但写不出来」或「心里有事想理一理」的时刻？  
2. 你平时写日记吗？频率？  
3. 你对 AI 陪写回忆的顾虑是什么？（隐私 / 假 / 不知道写啥）  

### 5.2 试用后问卷（核心，5–8 分钟）

**A. 行为（事实）**

1. 你完整体验了吗？□ 只聊了开头 □ 看到四隧道 □ 进入阶段二 □ 30 分钟以上  
2. 四隧道里你点了吗？□ 没点 □ 点了，因为：________  
3. 你会愿意 **下周再来一次** 吗？□ 愿意 □ 可能 □ 不愿意  

**B. 感受（1–5 分）**

4. 「被理解 / 被接住」程度：1 2 3 4 5  
5. 「想继续写下去」程度：1 2 3 4 5  
6. 「过程有趣 / 愿意探索」程度：1 2 3 4 5  

**C. 开放题（最重要）**

7. 哪一个瞬间你觉得「这玩意儿有用」？如果没有，卡在哪？  
8. 哪一个瞬间你想关掉页面？为什么？  
9. 如果每月 ¥29，你会付吗？□ 会 □ 不会 □ 看 ________  
10. 你愿意把谁再推荐来试用？（可选）  

### 5.3 10 分钟语音深访（仅对愿意的人，第 2 周）

按顺序问：

1. 复述一遍你上次聊的主题——你自己怎么理解这条「隧道」？  
2. 记忆图谱（阶段二）对你有意义吗？看不懂还是有帮助？  
3. 如果下周只能改 **一个地方**，你改什么？  
4. 你会把这个产品介绍成什么？（听用户原话，用于定位）  
5. 有什么让你担心隐私或不舒服的？

## 六、4 周节奏（你每周只做一件事）

### 第 1 周：接入 + 首次体验

| 你做什么 | 标准 |
|----------|------|
| 发出 10 份邀请，目标 **7 人** 真的打开 | 7/10 打开即合格 |
| 确保演示站稳定（VPS，非 Tunnel） | 无 500/502 |
| 收 **试用后问卷** | ≥5 份回收 |

**本周只改 bug**，不改大功能。

---

### 第 2 周：追问 + 第二次使用

| 你做什么 | 标准 |
|----------|------|
| 对 3–5 人做 **10 分钟语音** | 记下原话 |
| 邀请「愿意的人」 **再来第二次** | ≥3 人第二次打开 |
| 统计：从开场到点隧道的中位时间 | 心里有个数 |

**本周只改 1 个点**（三选一，别全做）：

- 开场引导文案  
- 四隧道卡片可读性  
- 进入阶段二后的第一句 AI 回复  

---

### 第 3 周：收敛价值主张

| 你做什么 | 标准 |
|----------|------|
| 把用户原话贴墙（10 条） | 找重复出现的词 |
| 写一句 **对外定位** 草稿 | 给用户念，看是否点头 |
| 问早鸟：「¥29/月 你愿意吗」 | ≥2 人认真考虑 |

**本周只改 1 个点**：阶段二「想继续写」的引导（或记忆图谱说明）。

---

### 第 4 周：决定去留

开 30 分钟 **给自己复盘**（填下表）：

| 指标 | 目标 | 实际 |
|------|------|------|
| 发出邀请 | 10 | |
| 至少体验 1 次 | ≥7 | |
| 问卷回收 | ≥5 | |
| 愿意第 2 次来 | ≥3 | |
| 愿意付费 / 早鸟 | ≥2 | |
| 愿意推荐朋友 | ≥2 | |

**决策：**

- **达标** → 扩到 20–30 人 + 做邀请码 + BYOK  
- **差一点** → 再跑 10 人，换一批画像（如多招写日记的人）  
- **不达标** → 暂停扩量，先改楔子（不是加功能，是改工作流引导）
